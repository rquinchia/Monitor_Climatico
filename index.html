Lectura operativa: mientras más bajo sea el bulbo húmedo, mayor potencial tiene la torre para rechazar calor por evaporación. El bulbo húmedo es el límite físico de aproximación, no una garantía de salida de agua.
Precisión: la carta usa presión atmosférica estimada por elevación, ecuaciones psicrométricas para humedad específica, entalpía y curvas de humedad relativa. Para diseño contractual debe validarse con carta ASHRAE oficial, presión barométrica medida y condiciones de diseño del proyecto.
Fuente climática: Open-Meteo Weather API y Open-Meteo Geocoding API. La ubicación automática requiere HTTPS o ejecución local en localhost. Si abres el archivo directamente y el navegador bloquea ubicación, prueba desde localhost.
